# AUREA Immobilien

Eine moderne und responsive Immobilien-Webseite als Portfolio-Projekt, entwickelt mit HTML, CSS und JavaScript.

**[Live-Demo ansehen](https://mavesso.github.io/aurea-immobilien/)**

## Über das Projekt

AUREA Immobilien ist eine fiktive Immobilienagentur mit einem modernen und eleganten Webdesign.

Ziel dieses Projekts war die Entwicklung einer benutzerfreundlichen Immobilien-Webseite mit interaktiver Suchfunktion, übersichtlichen Immobilienangeboten und individuellen Detailansichten.

Die Webseite wurde für Desktop, Tablet und Smartphone gestaltet.

## Funktionen

- Responsive Navigation mit mobilem Menü
- Moderne Startseite mit großem Immobilienbild
- Drei Immobilienangebote mit Bildern, Preisen und Informationen
- Interaktiver Suchfilter nach Standort, Immobilientyp und maximalem Preis
- Individuelle Detailansichten mit Bildern und Objektbeschreibungen
- Kontaktformular mit Demo-Bestätigung
- Optimierte Bilder für schnelle Ladezeiten

## Verwendete Technologien

- **HTML5** – Struktur und Inhalte
- **CSS3** – Design, Layout und responsive Darstellung
- **JavaScript** – Suchfilter, Detailansichten, Navigation und Formular
- **GitHub Pages** – Veröffentlichung der Webseite

## Hinweis

AUREA Immobilien ist ein fiktives Portfolio-Projekt. Sämtliche Immobilienangebote, Standorte und Preise dienen ausschließlich zur Demonstration.

Es werden keine echten Immobilien vermittelt. Das Kontaktformular versendet keine Nachrichten.
